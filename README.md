# The Best Advice I Ever Got

A deterministic Python entry for the [The Best Advice I Ever Got](https://make.fun/bounty/u-pangg7-the-best-advice-i-ever-got-358cefb0) competition on make.fun. The program writes the entry text to `entry.txt`, with no trailing newline. The readable source is `entry_source.py`; `main.py` is the official make.fun compress output of that source.

## Running

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out python3 main.py
cat /tmp/out/entry.txt
```

If `MAKEFUN_OUTPUT_DIR` is not set, the entry is written to `/output/entry.txt`.
